# Subscription Analysis Dashboard

An interactive data analysis dashboard built with Python and Streamlit to analyze subscription revenue, customer churn, plans, companies, countries, and revenue trends.

## Features

- Revenue analysis
- Customer and subscription analysis
- Churn analysis
- Plan-wise analysis
- Company and country-wise insights
- Monthly and quarterly revenue trends
- Interactive visualizations

## Tech Stack

- Python
- Pandas
- NumPy
- Streamlit
- Plotly
- Matplotlib
